## 可以做什么

- **浏览战场**：在三维地图上查看地形、部队、据点与行动路线。
- **回看战役进程**：沿时间轴播放、暂停、调整速度，或跳转到指定时刻。
- **观看历史讲解**：场景可包含关键事件说明、图片、视频与镜头安排。
- **全屏演示**：用于历史讲解、课堂展示和个人研究。
- **制作自己的场景**：编辑部队行动、地图标记、关键事件和讲解素材，保存后继续使用。

## 快速上手

1. **下载软件**：如果下载的是压缩包，先解压到本机文件夹，再双击其中的 EXE 启动。
2. **下载场景**：将地图场景包完整解压，找到包含 `scene.deepblue.json` 的文件夹。
3. **打开场景**：在软件顶部点击「打开场景目录」，选择该文件夹。
4. **开始浏览**：使用底部时间轴播放或定位；点击「沉浸演示」进入展示画面。

软件首次启动可以是空白场景。下载的战役需要按上述步骤打开。

部分场景设有开场和讲解暂停点，停住时按空格继续。如果场景安排了镜头，可开启「镜头预览」，观看随时间变化的镜头。

## 常见问题

**下载后为什么没有战役？**

软件和场景可以分别下载。请下载地图场景包，解压后通过「打开场景目录」载入。

**打开场景时应该选哪个文件夹？**

选择直接包含 `scene.deepblue.json` 的文件夹。如果解压后还有一层同名目录，请进入下一层查找。

**为什么图片、视频或模型缺失？**

先确认场景包已完整解压，并保留了 `media`、`models` 等目录。重新通过「打开场景目录」打开场景；若仍缺失，请反馈场景名称和软件版本。

**为什么播放到某个位置停住了？**

场景可以设置讲解暂停点，开场也可能等待播放。按空格或点击播放即可继续。

**更新软件会影响我的场景吗？**

请先备份自己编辑过的完整场景目录，并查看新版本的兼容性说明。更新软件时，不要用下载的示例场景覆盖自己的同名场景。
